# Murder Mystery

Enable **Hypixel → Modes → Murder Mystery**. Detection and its visuals identify an active round from the visible game sidebar, including team sidebars and formatted score rows. Proxy connection addresses work too. Lobbies and other games do not activate detection.

- All 47 weapon skins from the supplied screenshots are included. Variant signatures distinguish lapis, red dye, salmon, rose bushes, jungle saplings and coal from other variants of those items. Damaged tools still match.
- **Open weapon editor** immediately opens a Skeet themed searchable icon grid from ClickGUI, even while Hypixel is disabled. Default skins, Selected and All items tabs filter the grid. Hover for a full item name and registry signature. Click to toggle, use the mouse wheel or Page Up/Down to scroll, and use Restore defaults to recover the full preset. Apply commits the draft to the running settings; Cancel/Escape discards it. Both return to the previous screen. Loading a config never opens the editor. Config files change only with an explicit config save.
- The old six-item stock list upgrades in memory. Custom lists remain intact, including legacy unlocalized IDs. A plain registry ID matches all its variants; `dye@4`, for example, matches only lapis. The editor can select either individual variants or an any-variant entry.
- With **Path** enabled, **Murder Mystery lines** automatically overrides any normal target setting during an active round: route to a detected murderer while innocent, or to a detected bow holder while murderer. No separate target mode is needed. The closest eligible player is selected, with the usual Path range and friend/team filters. No route is drawn to random bystanders when a matching player is unknown. Disabling the relevant role option or leaving the game restores normal Path targeting. Bow sightings remain available after an item switch and are independent of the bow ESP toggle.
- Each newly detected murderer produces a client chat warning naming the player and weapon, once per player per round. The separate **Announce murderer** setting controls public server chat and is off by default.
- **Highlight dropped gold** and **Gold highlight color** highlight all loaded gold-ingot drops through walls, even with ItemESP disabled. Disabling the option leaves ordinary ItemESP behavior available.
- **Hypixel → Path to closest gold** adds a second route when **Path** is enabled. It selects the closest loaded gold ingot within Path's Max Range, uses the gold highlight color, and follows the same collision checks and line/depth settings. It works with gold ESP off and can appear alongside the murderer/bow-holder route. Collected, dead, empty or unloaded drops are removed as targets; the next closest drop is selected. Both searches share Path's per-tick search budget. The option is off by default.

Local verification covers the real item registry, scoreboard roles, role transitions, target filtering, drop filtering, editor interactions and OpenGL rendering. It does not connect to a live Hypixel match.
