# Inventory, building and model changes

- Inventory Manager plans sword placement first, then armour equipment/upgrades, then other layout assignments and cleanup. Armour can equip even without an explicit layout entry. Drop Duplicates keeps one best item per tool/armour type, including ties and already equipped armour; ignored slots remain protected. Tools include material quality and Efficiency in their score.
- ChestStealer's Check Title accepts any displayed title containing `chest`, case-insensitively, including custom titles.
- Inventory Manager and ChestStealer share a smooth rounded slot outline with a 1.6-second opacity/glow pulse. Highlights use the displayed container's actual origin, including the inventory's potion-effect sidebar shift, and retain the Inventory Editor position color.
- Local command, module and script messages share the `[Vibe]` prefix. Its letters fade through a continuous rainbow at render time, so messages already in chat animate too. Native wrapping, message fading/shadows and clickable/hoverable components are retained.
- BedAura selects its rotation before movement and supplies a block hit and attack-key input at the same pre-dispatch boundary as KillAura. Minecraft's `clickMouse` and held-block-input handlers own digging, conditional swings, hit delays, aborts and target changes. The former post-walking swing/dig callback and reset-blocking hook are removed. Slot restoration waits for vanilla's next input tick. This addresses the `Post: animation v1.8` timing recorded in the client logs. Regression tests capture and serialize packets from the real Minecraft handlers, player swing/walking writer and mining controller, comparing the action stream with ordinary held input; only transport, effects and deterministic block hardness are fixtures. Live server acceptance is not certified.
- ESP text labels no longer draw backgrounds, including when an older config enables them. Their background controls are hidden. Existing text layout, colors, fonts, outlines, shadows, bars and non-text fills are preserved.
- Raven integration audit: idle walking-packet transport preserves vanilla yaw exactly, input wrappers retain existing input at installation, disabling a producer immediately discards its owned correction, and autoblock reset preserves unowned use input. See [movement audit and verification](MOVEMENT_INACTIVE_AUDIT.md).
- Scaffold adds **Start Options** (Sneak, Faster Rotate), a 1.0–5.0 **Start Rotation Multiplier**, **Less Micro Adjustments**, and **Sneak on Fail** when regular Sneak is off. Start actions stop after initial alignment. Normal/GodBridge keep the chosen side through a larger middle band; the Hypixel ground profile uses the same wider tolerance. Less Micro holds valid aim, suppresses optional yaw jitter, and changes pitch when the face can no longer be hit. Sneak on Fail tests support at the predicted next step and releases when support returns.
- TickBase defaults to **Screenshot**. A brief real pause (50 ms per selected tick, capped at 250 ms) lets vanilla's timer catch up, using collision-checked movement prediction and a cooldown. It does not add recursive ticks, fake movement packets, or alter keepalive replies in this mode. **Burst** retains the previous behavior for existing use cases. Actual movement depends on held inputs, world state and server behavior; no live Grim acceptance claim is made.

Named configs change only through the explicit config save workflow; current working settings also survive restarts through separate session recovery. See [config behavior](CONFIGS.md) and [custom model settings](CUSTOM_MODELS.md) for details.
